SHEET 12 — ABOUT

About

I started by learning how to keep systems running — help desks, Active Directory, Exchange migrations, ATM upgrades, network hardware. Over a decade, that grew into managing identity and security for enterprise environments with 15,000+ users.

Along the way I spent two years on the other side of AI: evaluating LLM outputs, auditing hallucinations, and building multi-turn safety tests. That work showed me exactly where AI systems break — and that the fix is rarely the model itself.

That same discipline now shows up as working code: REST APIs built with Node.js and Express, Supabase Auth and JWT-gated endpoints, PostgreSQL and SQLite persistence with parameterised queries, and Dockerized services — each documented with OpenAPI/Swagger rather than left implicit. The systems discipline stays the same — reliability, security, auditability. Only the surface has changed.

The next stretch: an AI document ingestion pipeline that extracts structured data from PDFs and receipts, validates it with Zod, and writes it straight into a database — zero manual typing, without skipping validation.
